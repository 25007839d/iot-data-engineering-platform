MACHINE LEARNING
│
├── SUPERVISED LEARNING
│
│   ├── REGRESSION
│   │
│   │   ├── Linear Regression
│   │   │   → Predict continuous values using a straight-line relationship.
│   │   │   → Use Case: House Price Prediction
│   │   │
│   │   ├── Polynomial Regression
│   │   │   → Predict non-linear relationships using polynomial curves.
│   │   │   → Use Case: Sales Growth Forecasting
│   │   │
│   │   ├── Decision Tree Regressor
│   │   │   → Tree-based prediction for numerical values.
│   │   │   → Use Case: Revenue Prediction
│   │   │
│   │   ├── Random Forest Regressor
│   │   │   → Multiple trees combined for better accuracy.
│   │   │   → Use Case: Stock Price Estimation
│   │   │
│   │   └── XGBoost Regressor
│   │       → Boosted trees for highly accurate predictions.
│   │       → Use Case: Demand Forecasting
│   │
│   └── CLASSIFICATION
│       │
│       ├── Logistic Regression
│       │   → Predicts probability of a class.
│       │   → Use Case: Spam Detection
│       │
│       ├── KNN (K-Nearest Neighbors)
│       │   → Predicts based on nearest similar records.
│       │   → Use Case: Product Recommendation
│       │
│       ├── Naive Bayes
│       │   → Probability-based classifier using Bayes theorem.
│       │   → Use Case: Email Spam Filtering
│       │
│       ├── Decision Tree
│       │   → Rule-based classification using tree structure.
│       │   → Use Case: Loan Approval
│       │
│       ├── Random Forest
│       │   → Ensemble of multiple decision trees.
│       │   → Use Case: Fraud Detection
│       │
│       ├── XGBoost
│       │   → Gradient boosting algorithm with high accuracy.
│       │   → Use Case: Customer Churn Prediction
│       │
│       └── SVM
│           → Separates classes using optimal boundaries.
│           → Use Case: Face Recognition
│
├── UNSUPERVISED LEARNING
│
│   ├── CLUSTERING
│   │
│   │   ├── K-Means

│   │   │   → Use Case: Customer Segmentation
│   │   │
│   │   ├── Hierarchical Clustering
│   │   │   → Creates clusters in tree hierarchy.
│   │   │   → Use Case: Gene Analysis
│   │   │
│   │   ├── DBSCAN
│   │   │   → Density-based clustering with outlier detection.
│   │   │   → Use Case: GPS Location Analysis
│   │   │
│   │   └── Gaussian Mixture Model
│   │       → Probabilistic clustering algorithm.
│   │       → Use Case: Customer Behavior Analysis
│   │
│   ├── ASSOCIATION RULES
│   │
│   │   ├── Apriori

│   │   │   → Use Case: Market Basket Analysis
│   │   │
│   │   └── FP-Growth

│   │       → Use Case: Product Recommendation
│   │
│   └── DIMENSIONALITY REDUCTION
